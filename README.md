# Twin Cities Animal Rescue

A four-page website for Twin Cities Animal Rescue, a fictional community nonprofit from the course's client scenarios. Built for Introduction to Web Development.

**Live site:** https://kmuirhead.github.io/CS1005/

## Pages

- `index.html`: mission, impact numbers, and ways to help
- `services.html`: adoption, fostering, and volunteering, plus the "Find Your Way to Help" tool
- `about.html`: the rescue's story, a message from the director, values, and partners
- `contact.html`: the volunteer and foster interest form, service area, and office hours

## Project stages

Each stage is tagged in this repo:

- `touchstone-2`: HTML structure
- `touchstone-3`: CSS visual design and responsive layout
- `touchstone-4`: JavaScript feature, form validation, and localStorage
- `touchstone-5`: final version

Earlier stages can also be viewed live:
